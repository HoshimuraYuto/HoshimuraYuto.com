# sky

日時と観測地(緯度経度)から、その場所の空を返す。太陽・月の高度と方位、月の輝面比・欠け方の向き・月齢、見えている恒星(高度・方位・等級・色指数)。惑星は扱わない。

サイトの他のコードからimportするのは`src/utils/interpolate.ts`(線形補間の小さな関数)だけ。切り出すときはそれも一緒に持ち出す。

## 使い方

```ts
import { skyAt } from "./sky";

const sky = skyAt(new Date("2026-11-20T13:00:00Z"), {
  latitude: 35.6586,
  longitude: 139.7454,
});
sky.sun.altitude; // 度。方位は北0度・時計回り
sky.moon.brightLimbAngle; // 月の輝いている縁の向き。真上0度・時計回り
sky.stars; // 地平線より上で、その空の明るさで見える星。明るい順
```

太陽と月は[suncalc](https://github.com/mourner/suncalc)で求める。

## 確かめ方

```sh
pnpm vitest run src/lib/sky
```

恒星の位置は[astronomy-engine](https://github.com/cosinekitty/astronomy) 2.1.19(devDependenciesのみ。配布物には入らない)と照合する。

| 対象                                                             | 照合内容                     | 許容誤差 | 実測の最大誤差 |
| ---------------------------------------------------------------- | ---------------------------- | -------- | -------------- |
| 恒星(北極星・シリウス・ベガ・アークトゥルス・ベテルギウス)×4日時 | 大気差なしの地平座標の角距離 | 0.05度   | 0.0081度       |

実測値は、照合用の4日時(2026-11-12T03:00Z・2026-11-20T13:00Z・2000-01-01T12:00Z・2040-06-21T15:30Z)と明るい60星・全1451星について角距離の最大を一時的なテストで出したもの。

## 計算の中身

- 恒星時: グリニッジ平均恒星時(Meeus式12.4)に東経を足す
- 歳差: J2000.0の位置を観測日の平均春分点へ移す(Meeus式21.3・21.4の厳密式。起点をJ2000.0にとり、起点の元期に関する項は0)
- 地平座標: Meeus式13.5・13.6。方位は北0度・時計回りに直している
- 月の欠け方の向き: 月から太陽へ向かう大円の向き(天球上の方位角)
- 月齢: suncalcの位相から平均朔望月で前の新月の見当をつけ、位相で4回詰めて前の新月を探し、そこからの経過日数

## 既知の限界

恒星の位置で入れていない補正と、おおよそのずれ。

| 入れていない補正                   | ずれの大きさ                                                            |
| ---------------------------------- | ----------------------------------------------------------------------- |
| 章動                               | 最大約17秒角(0.005度)                                                   |
| 年周光行差                         | 最大約20.5秒角(0.006度)                                                 |
| 固有運動                           | 2026年で多くの星は数秒角以下。大きい星ではアークトゥルス約1分角(0.02度) |
| 視恒星時(平均恒星時との差、分点差) | 最大約1.1秒(時間)。角度で約17秒角                                       |
| 大気差                             | 地平線で約0.5度、高度10度で約0.1度。恒星は大気差なしの位置を返す        |
| UTとTTの区別                       | 約69秒。恒星時の計算に入れていないので、ずれは無視できる大きさ          |

そのほか:

- 星表は5.0等までで止めている。HYGの視等級をそのまま使い、変光星は代表値のまま
- 太陽・月の精度はsuncalc次第(suncalcのREADMEでは位置約0.08〜0.09度)
- 惑星は扱わない

## 星のデータ

`stars.json`は[HYG Database](https://codeberg.org/astronexus/hyg) v4.1(David Nash、[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/))から作った。

- 抽出条件: 視等級(`mag`)5.0以下、かつ東京(北緯35.6586度)で地平線より上に来うる赤緯(`dec` > −54.3414度)。太陽(`id` 0)を除く。1451個
- 残した列: `ra`(時→度に換算、J2000)、`dec`(度、J2000)、`mag`、`ci`(B−V。欠けている星は0)。明るい順に並べた
- 改変内容は「視等級5.0等までで、東京から見える赤緯のものを抽出。太陽を除外。赤経を度に換算。列を赤経・赤緯・等級・色指数に削減(色指数の欠けは0)。明るい順に並べ替え」。この改変物も同じライセンス(CC BY-SA 4.0)
