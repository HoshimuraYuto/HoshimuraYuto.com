# weather

日時から、その時刻の天気を返す。雲の層(雲量・雲底の高さ)、降っているもの(雨・雪・みぞれなどと強さ)、雷、霧・もや、視程、風、地面の様子(濡れ方と積雪)。目に見えるものだけを扱う。気温は地面の様子を決めるためだけに読み、気圧は扱わない。

サイトの他のコードをimportしない。このディレクトリだけで切り出せる。通信は`fetch`だけを使い、依存パッケージはない。

## 使い方

```ts
import { iemMetarSource, jmaForecastSource, weatherAt } from "./weather";

const weather = await weatherAt(new Date("2026-10-24T04:00:00Z"), [
  iemMetarSource({ station: "RJTT" }),
  jmaForecastSource({ office: "130000", area: "130010" }),
]);
weather?.cloudCover; // 0〜1
weather?.precipitation; // { kind: "rain", intensity: "moderate" } または undefined
weather?.ground; // { wet: 1, snow: 0 }。直前の報が分からない入手先(予報)では付かない
weather?.origin.raw; // 元の文。METARそのもの、または予報の天気コードと文
```

- 入手先は並べた順に尋ね、最初に答えたものを返す
- `weatherAt`は失敗しない。通信の失敗、形の違う応答、時間切れ(既定8秒)はどれも`undefined`になる

## 入手先

| 入手先              | 何が取れるか                              | いつの分か                           | 利用条件                                                                  |
| ------------------- | ----------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------- |
| `iemMetarSource`    | 空港のMETAR(観測)。雲の層、現象、視程、風 | 過去と現在。指定日時以前で最新の報   | Iowa Environmental Mesonet。パブリックドメイン、出典表示は推奨            |
| `jmaForecastSource` | 気象庁の天気予報。天気コードと文          | 最新の発表から先だけ。過去の分はない | 公共データ利用規約(第1.0版)。出典の表示が必要。加工したときはその旨も書く |

- METAR: `https://mesonet.agron.iastate.edu/cgi-bin/request/asos.py?station=RJTT&data=metar&year1=…&month1=…&day1=…&year2=…&month2=…&day2=…&tz=UTC&format=onlycomma`。指定日時の6時間前が入る日から翌日までを、UTCの日単位で尋ねる(2〜3日分)。応答は`station,valid,metar`のCSVで、`valid`はUTC
- 気象庁: `https://www.jma.go.jp/bosai/forecast/data/forecast/130000.json`。1つ目の報の、1つ目の`timeSeries`から、`area.code`が合う地域の`weatherCodes`と`weathers`を読む
- どちらもキーは要らず、ブラウザから直接取れる(`Access-Control-Allow-Origin: *`。2026-11-12に確認)
- 気象庁の出典の書き方: 「出典：気象庁ホームページ(URL)」。このライブラリは天気コードを雲量や降るものに読み替えているので、加工した旨も書く

## METARの読み方

読むのは観測の部分だけ。`NOSIG`・`BECMG`・`TEMPO`(傾向予報)と`RMK`(国内向けの注記)より後ろは読まない。

| 読むもの | 読み方                                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------------------------- |
| 雲量     | `FEW` 1〜2/8、`SCT` 3〜4/8、`BKN` 5〜7/8、`OVC` 8/8。`cover`は範囲の中央。全体の雲量は最も広い層のもの           |
| 雲底     | 3桁の数字×100フィート。`///`は`undefined`                                                                        |
| 雲なし   | `CAVOK`・`NSC`・`NCD`・`SKC`・`CLR`は層なし。`CAVOK`は視程10km以上も意味する                                     |
| 鉛直視程 | `VV`は空が見えない報なので、全天の雲にする                                                                       |
| 現象     | 強さ(`-`弱い、なし 並、`+`強い)、降るもの(`DZ` `RA` `SN` `SG` `PL` `GR` `GS` `UP`)、視程障害(`BR` `FG` `HZ`など) |
| 降るもの | 最初に書かれた種類を採る。雨の類と雪の類が混じればみぞれ。`UP`(種類不明)は雨にする                               |
| 雷       | `TS`                                                                                                             |
| 付近     | `VC`が付く現象は、その場の天気にしない                                                                           |
| 霧       | `FG`は霧。`MIFG`・`BCFG`・`PRFG`(地面付近・散在・部分的)はもやにする                                             |
| 視程     | 4桁の数字(メートル)。`9999`は10km以上                                                                            |
| 風       | `dddffKT`または`MPS`。`VRB`は風向なし。`Gff`は突風(`gust`)                                                       |
| 氷の粒   | `GR`ひょう、`GS`あられ、`PL`凍雨。先頭なら降るものの種類、雨や雪の後ろなら`ice`(まじり)                          |
| 着氷性   | `FZ`の付く雨・霧雨は`freezing`                                                                                   |
| 視程障害 | `HZ`煙霧、`FU`煙、`VA`火山灰、`DU`・`SA`砂じん                                                                   |
| その他   | `SQ`スコール、`FC`竜巻、`DS`・`SS`砂じんあらし、`PO`塵旋風、`BL`・`DR`の付く砂じんは風で舞う砂じん(`phenomena`)  |
| 気温     | `TT/TdTd`の前半(℃)。`M`は零下。`M00`は0にする。地面の様子にだけ使う                                              |

雲量の区分は、WMO-No. 306『Manual on Codes』Volume I.1、FM 15 METARの規則15.9.1.1による。現象の略語は同書のコード表4678([codes.wmo.int/306/4678](https://codes.wmo.int/306/4678))による。

## 地面の様子の決め方

`ground.ts`の`groundAt(reports, date)`が、指定日時の直前6時間の報だけから決める。ページを開いてからの時間は使わないので、同じ報と同じ日時なら同じ値になる。`iemMetarSource`は、天気を読んだのと同じ応答から計算して`Weather.ground`に入れる(問い合わせは増えない)。

- `wet`(0〜1): 雨が降っている間に増え、止むと減る。増え方は1時間あたり弱い雨0.8、並2、強い雨5(霧雨はその半分)。乾き方は1時間あたり0.2に、風速1m/sごとに0.02を足す
- `snow`(0〜1): 雪が降っている間に増える。増え方は1時間あたり弱い雪0.25、並0.7、強い雪1.5(みぞれはその半分)。気温1℃以下なら全部積もり、4℃以上なら積もらず地面を濡らし、その間は割合で分ける。気温のない報では積もるものとする
- 積もった雪は、気温が2℃を超えると1℃・1時間あたり0.08ずつ融けて地面を濡らし、雨に降られるとその雨の量の0.2だけ減る
- 1つの報は次の報まで続いたものとして数える。次の報がないときは1時間まで

数値はどれも測った値ではない。METARは降り方を区分でしか報じず、降水量も積雪の深さも含まないので、見た目が自然になるようにこのサイトのために決めた(`constants.ts`の`GROUND_*`)。

## 気象庁の天気コードの読み方

コードと名前の対応表は、気象庁の天気予報ページ(`https://www.jma.go.jp/bosai/forecast/`)のHTMLに書かれた`TELOPS`という表から取った。気象庁が仕様として公開しているものではない。

- 百の位を分類に使う。1は晴、2は曇、3は雨、4は雪
- 雲量は予報に含まれないので、分類ごとに決めた値を使う(晴0.2、曇0.85、雨と雪1)。気象庁の値ではなく、このサイトのために決めた値
- 描くのはコードの先頭の天気だけ。「晴後曇」は期間を通して晴として扱う
- 209は霧、340・361・371(雪か雨)は雪、306・308・405・406・407は強い降り方、350・450は雷として扱う

## 既知の限界

- 観測地点は空港。RJTT(羽田)は東京タワーの南約11km、海沿いにあり、都心の空と違うことがある
- METARの雲量は区分(1〜2/8など)で、正確な値ではない。`cover`はその中央を採っている
- METARが報じる雲は、運航に関わるもの(雲底が約1500m未満、または積乱雲・塔状積雲)に限られることがある。`CAVOK`や`NSC`は「高い雲もない」という意味ではない
- METARは定時で30分ごと。その間の変化は、次の報か臨時の報(SPECI)が出るまで分からない。2時間以内に報がなければ、観測はないものとして扱う
- IEMに当日の報が入るまでの遅れは決まっていない。2026-11-12 18:40(日本時間)に尋ねたとき、最新は18:00の報で、18:30の報はまだなかった
- IEMの取得回数の上限は確かめていない。1回の問い合わせは2〜3日分に絞っている
- 気象庁のJSONには公開された仕様書がなく、予告なく形が変わりうる。形が違えば`undefined`を返す
- 気象庁の予報は地域(東京地方)全体の、半日〜1日単位のもの。その時刻のその場所の天気ではない
- 地面の様子は降った時間と強さの区分からの見積もりで、実際の路面や積雪の観測ではない。6時間より前に降ったものは数えないので、何日も残る雪は表せない。日射や地面の温度も見ていない
- 予報には直前の報がないので、地面の様子は付かない
- 気象庁の予報は最新の発表しか取れない。まだ来ていない日時の結果は、発表が替わると変わる
- 過去の日時の結果はMETARで決まるので変わらない。ただしIEMが後から記録を訂正・追加した場合は変わりうる
- 竜巻・砂じんあらし・ひょうなどの見せ方は、羽田で観測された例がないため、作例の報でしか画面を確かめていない
- METARの竜巻(`FC`)は空港で見えたものに限る。都心の竜巻注意情報などは扱わない
- WMO-No. 306は、規則15.9.1.1の本文を写しで確かめた。15.6(視程)・15.10(CAVOK)・15.14(傾向予報)・15.15(RMK)は節の対応だけを確かめ、本文は読めていない
